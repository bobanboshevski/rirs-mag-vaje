Apartment Management System

👥 Team Members

  • Boban Boshevski, FERI IPT

📝 Project Description

This project is a comprehensive apartment management system designed to streamline property management operations. The system includes features for managing apartments, reservations, guests, payments, and maintenance requests.

The application is built with modern web technologies and follows CI/CD best practices with automated testing, building, and deployment pipelines.

🛠️ Technology Stack

Next.js
React
Node.js
Express
Docker
GitHub Actions

🚀 Deployment

Frontend (Render) Backend API (Render) GitHub Repository

📊 CI/CD Pipeline

Automated Pipeline includes:

  • Automated testing with coverage reports
  • Docker image building and pushing to Docker Hub
  • Deployment to Render.com
  • GitHub Pages deployment for documentation
  • Caching for faster builds (node_modules, Docker layers)
